# 下载文件说明

## 文件命名规范

请将 CAD 文件按以下命名放入此文件夹：

- `2026-cad.zip` - 2025-2026赛季 ARTEMIS 机器人 CAD 文件
- `2025-cad.zip` - 2024-2025赛季 POSEIDON 机器人 CAD 文件  
- `2024-cad.zip` - 2023-2024赛季 BEYOND 机器人 CAD 文件
- `2023-cad.zip` - 2022-2023赛季机器人 CAD 文件
- 以此类推...

## 文件准备

1. 将每个赛季的 CAD 文件（如 Onshape 导出的 STEP/STL 文件）打包成 ZIP
2. 按上述命名规范重命名
3. 放入此文件夹
4. 推送到 GitHub

## 注意事项

- 文件大小尽量控制在 50MB 以内（GitHub 单文件限制 100MB）
- 如果文件过大，考虑使用 Git LFS 或外部云存储链接
- 确保文件中不包含敏感信息
